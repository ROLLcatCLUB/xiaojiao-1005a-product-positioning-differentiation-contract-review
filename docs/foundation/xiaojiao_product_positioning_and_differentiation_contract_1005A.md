## First Identity

`	ext
teacher_work_state_driven_intelligent_organization_system
`

Xiaojiao is not a better generator. Xiaojiao is a system that organizes teacher work from persistent Work State.

## Not First Identity

`	ext
AI lesson generator
PPT / courseware generator
smart classroom platform
resource library / knowledge base
student evaluation board
school digitization backend
`

## Core Question For Future Features

`	ext
Is this Xiaojiao orchestrating a business scene,
or is Xiaojiao becoming that business scene itself?
`

If Xiaojiao is becoming the business scene itself, the route is risky and needs repositioning.

## Differentiation Principles

`	ext
state_before_function
object_before_page
continuity_before_single_generation
layered_focus_surface_and_complex_studio
resources_and_knowledge_as_support_layer
analysis_must_flow_back_to_action
teacher_retains_authority
`

## Route Constraints

`	ext

## Boundary

This is a positioning contract only. It does not install dependencies, modify frontend, connect runtime, call provider/model, write database or memory, write Feishu, create formal export, enter classroom runtime, or finalize a product route.
